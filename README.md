# 📊 Databricks Retail Analytics & BI Dashboard

## Project Overview

This project focuses on analyzing retail sales and customer data using **Databricks SQL** to transform raw data into meaningful business insights.

It features interactive dashboards designed to monitor sales performance, analyze customer behavior, track orders, and evaluate business KPIs.

The objective is to demonstrate how Databricks can support data-driven decision-making through SQL analytics and business intelligence.

## 🛠️ Technologies & Tools

- **Databricks:** Data analytics platform
- **Databricks SQL:** Data querying and analysis
- **SQL:** Data exploration and KPI calculations
- **Delta Lake:** Data storage and management
- **Unity Catalog:** Data governance
- **Databricks Dashboards:** Business intelligence and visualization

## 📊 Dashboard Overview

### 1. Order Analysis

Focuses on retail sales and order performance.

**Key Performance Indicators:**
- Total Sales
- Total Orders
- Average Order Value
- Sales Target
- Target Achievement (%)
- Remaining Sales to Target

**Business Insights:**
- Sales performance monitoring
- Order trends and distribution
- Actual sales versus business targets
- Revenue performance analysis

### 2. Customer Analysis

Provides insights into customer behavior and purchasing patterns.

**Key Analysis Areas:**
- Total Customers
- Customer Segmentation
- Loyalty Levels
- Customer Distribution
- Customer Purchasing Behavior

## 📈 Key Business Metrics

| KPI | Calculation |
|---|---|
| Total Sales | Sum of sales amount |
| Total Orders | Count of orders |
| Average Order Value | Total Sales / Total Orders |
| Target Achievement | Actual Sales / Sales Target × 100 |
| Remaining to Target | Sales Target − Actual Sales |
